# Unwhoop

Native iOS app for the user's WHOOP 5.0 band, installed with Sideloadly.
Band pairing and local sensor history transfers are the current working scope.
The app uses Bluetooth and local storage, with no account or cloud.

Daily scoring is not yet wired to ingested raw data. The UI must state this
and leave scores unavailable. Raw transfers can be exported from Data.

The current task fixes Sync Now and brings the native interface close to the
WHOOP app's dark dashboard. Preserve existing disclaimer acceptance, paired
